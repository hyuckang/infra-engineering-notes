# 인프라 엔지니어링 노트

인프라를 설계하고 운영하며 배운 개념과 실무 경험을 기록합니다.

컨테이너와 Kubernetes의 동작 원리부터 배포와 운영 과정에서 마주하는 문제, 관련 자격증 학습 자료까지 정리합니다. 앞으로 AWS, Linux, SRE, CI/CD 등으로 주제를 넓혀갈 예정입니다.

## 이 책의 방향

- 기술을 사용하는 방법과 함께 동작 원리와 선택의 이유를 살펴봅니다.
- 실무에서 겪은 문제와 해결 과정, 운영할 때 고려할 점을 기록합니다.
- 학습과 경험이 쌓일 때마다 내용을 추가하고 다듬습니다.

관심 있는 주제부터 찾아 읽고, 필요한 순간에 다시 펼쳐볼 수 있는 노트를 지향합니다.
