# 30-05. [CKS (Certified Kubernetes Security Specialist)](https://training.linuxfoundation.org/certification/certified-kubernetes-security-specialist-cks/)

## Cluster Setup : 15%
- Restrict traffic with network policies
- Audit component configuration against CIS benchmarks
- Configure TLS for Ingress
- Protect node endpoints and metadata
- Check binary integrity before installation

## Cluster Hardening : 15%
- Limit RBAC permissions and ServiceAccount access
- Restrict API server access
- Patch vulnerabilities through cluster upgrades

## System Hardening : 10%
- Remove unnecessary host software
- Limit host privileges and external network access
- Apply AppArmor and seccomp profiles

## Minimize Microservice Vulnerabilities : 20%
- Apply Pod Security Standards and protect Secrets
- Isolate tenants and sandbox workloads
- Encrypt traffic between Pods with Cilium

## Supply Chain Security : 20%
- Reduce base image size and contents
- Trace dependencies through SBOMs, pipelines and repositories
- Restrict registries and verify artifact signatures
- Statically analyze workload manifests and images

## Monitoring, Logging and Runtime Security : 20%
- Identify suspicious behavior across infrastructure, networks and workloads
- Investigate attack stages and identities involved
- Enforce immutable containers at runtime
- Review API access through audit logs
