# 30-06. [CKNE (Certified Kubernetes Network Engineer)](https://training.linuxfoundation.org/certification/certified-kubernetes-network-engineer-ckne/)

## Core Infrastructure and CNI : 15%
- Install and configure CNI plugins
- Plan Pod CIDRs and IP allocation
- Diagnose packet flow with ip, iptables and tcpdump
- Debug Pod connectivity and DNS
- Configure Pods with multiple interfaces

## Service Networking and DNS : 25%
- Configure Layer 4 Services
- Explain kube-proxy and CNI-based alternatives
- Customize CoreDNS for service discovery
- Diagnose Service traffic and manage endpoint availability
- Route requests with Gateway and HTTPRoute resources

## Advanced Traffic Management : 20%
- Optimize network traffic for LLM workloads
- Expose networks through routing
- Direct outbound traffic through egress gateways
- Discover services and balance traffic across clusters

## Network Security and Policy : 25%
- Enforce traffic restrictions with NetworkPolicy
- Encrypt traffic at node and Pod level
- Manage certificates for Gateway TLS
- Authenticate and authorize Pod traffic

## Observability : 15%
- Assess network health with metrics
- Trace end-to-end performance issues
- Review traffic logs for audit evidence
