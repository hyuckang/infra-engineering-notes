# 30-04. [KCSA (Kubernetes and Cloud Native Security Associate)](https://training.linuxfoundation.org/certification/kubernetes-and-cloud-native-security-associate-kcsa/)

## Overview of Cloud Native Security : 14%
- Relate the four Cs to infrastructure and cloud provider responsibilities
- Apply security frameworks and isolation controls
- Protect artifact repositories, images, workloads and application code

## Kubernetes Cluster Component Security : 22%
- Secure the API server, etcd, scheduler and controller manager
- Review kubelet, runtime, Pod and kube-proxy security
- Protect clients, storage and container networks

## Kubernetes Security Fundamentals : 22%
- Enforce Pod Security Standards through admission
- Manage authentication, authorization and Secrets
- Segment workloads with isolation controls and network policies
- Review API activity through audit logs

## Kubernetes Threat Model : 16%
- Trace data flows across trust boundaries
- Recognize persistence, service disruption and malicious execution in workloads
- Assess network threats, sensitive data exposure and privilege escalation

## Platform Security : 16%
- Secure software supply chains and image registries
- Use observability to assess platform security
- Secure connectivity with service mesh controls and PKI
- Evaluate workloads at admission

## Compliance and Security Frameworks : 10%
- Apply compliance and threat modeling frameworks
- Assess supply chain compliance
- Automate compliance checks
